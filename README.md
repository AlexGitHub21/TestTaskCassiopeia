## YML Feed Generator (Test Task)

### Описание

Реализация функции генерации YML-фида для Яндекс Директ.

Задача:
- исправить ошибки генерации YML;
- фильтровать некорректные товары;
- корректно обрабатывать цены и наличие;
- исключить дубли категорий;
- обеспечить корректное экранирование XML-символов;
- добавить автоматические тесты.

⸻

### Реализация

Основная логика находится в feed_task.py.

Что было исправлено

- фильтрация товаров по условиям выгрузки
- корректная обработка price / oldprice
- проверка наличия товара
- удаление дублей категорий
- экранирование XML-символов
- исправление структуры YML (категории → офферы)
- корректный формат даты

### Тесты

Запуск тестов: python -m pytest
